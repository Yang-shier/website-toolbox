# 建站工具箱

一个本地静态网页工具箱，用来处理建站过程中常见的内容整理任务：HTML 格式化、导航填充、联系方式替换、文本处理、图片链接替换、禁词替换、草稿保存和工作区备份。

## 打开方式

直接打开 `index.html`，页面会跳转到主工具页。

如果默认禁词库没有加载，建议在项目目录启动本地静态服务后访问：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4173/`。

## 功能概览

- **HTML格式化**：支持富文本/源代码输入，清理杂乱标签、样式、空格、空段落和危险内容，可自动识别小标题、设置图片宽度、禁词替换、指定文字加粗或加类名。
- **HTML 格式化**：支持富文本/源代码输入，清理杂乱标签、样式、空格、空段落和危险内容，可自动识别小标题、设置图片宽度、禁词替换、指定文字加粗或加类名。
- **导航填充**：从源导航代码提取父级栏目和子级栏目，填充到目标模板的重复块结构中。
- **联系方式替换**：从联系人文本提取公司、联系人、电话、邮箱、地址等字段，识别目标 HTML 中的联系方式区域并预览替换。
- **文本处理**：提供空格、大小写、标点、换行、去重、排序、编号等纯文本处理。
- **图片链接替换**：按顺序替换 HTML/CSS 中的图片链接，支持全部图片链接、仅背景图片或不替换背景图片。
- **工作区备份**：主要输入区会自动保存到浏览器本地，也可导出/导入工作区 JSON。
- 每个工具区都有 **填入示例** 按钮，可以快速放入示例数据查看效果。

## 自动保存草稿

主要输入区会自动保存到浏览器本地存储，刷新页面后会恢复未完成内容。点击对应工具区的清空按钮时，会同步清除该工具区的草稿。

## 工作区备份

页面顶部提供 **导出工作区** 和 **导入工作区**：

- **导出工作区**：把当前主要输入内容保存为 `site-toolbox-workspace.json`。
- **导入工作区**：选择之前导出的 JSON 文件，恢复各工具区输入内容。

## 测试

在 PowerShell 中运行：

```powershell
npm.cmd test
```

测试会覆盖核心逻辑、资源引用、页面可见功能、禁词替换、安全清理和静态结构检查。
