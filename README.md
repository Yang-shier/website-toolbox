# 建站工具箱

## 清空撤回

清空按钮不再弹出确认。清空后可以点击旁边的 **撤回**，恢复刚刚清掉的内容。

一个本地静态网页工具箱，用来处理建站时常见的内容整理任务：HTML格式化、导航填充、联系方式替换和文本处理。

## 打开方式

- 直接打开 `index.html`，会自动跳转到主页面。
- 如果默认禁词库没有加载，建议在项目目录启动本地静态服务后访问页面。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4173/`。

## 功能

- **HTML格式化**：清理内联样式、整理段落、处理图片宽度、自动识别小标题，并对输出做安全清理。
- **导航填充**：从源导航代码提取父级和子级栏目，再填充到目标模板。
- **联系方式替换**：从联系人文本提取公司、姓名、电话、邮箱、地址等字段，并替换到现有 HTML 模板。
- **文本处理**：处理空格、空行、大小写、标点转换、去重、排序和编号。

每个工具区都有 **填入示例** 按钮，可以快速放入示例数据来查看效果。

## 自动保存草稿

主要输入区会自动保存到浏览器本地存储，刷新页面后会恢复未完成内容。点击对应工具区的清空按钮时，会同步清除该工具区的草稿。

## 防误清空

四个主要工具区在有内容时点击清空，会先弹出确认。输入区为空时不会打扰，仍会直接执行清空流程。

## 工作区备份

页面顶部提供 **导出工作区** 和 **导入工作区**：

- **导出工作区**：把当前主要输入内容保存为 `site-toolbox-workspace.json`。
- **导入工作区**：选择之前导出的 JSON 文件，恢复各工具区输入内容。

这适合在不同浏览器、不同电脑之间迁移当前工作内容。

## 测试

在 PowerShell 中建议使用：

```powershell
npm.cmd test
```

当前测试会自动发现 `tests/*.test.js`，覆盖核心逻辑、资源引用、页面可见功能、安全清理和静态结构检查。
