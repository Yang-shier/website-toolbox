版本更新说明

这里记录当前功能、常用操作和后续更新。以后每次添加功能，都在这个页面补一条更新说明。

当前功能

HTML 格式化 支持富文本和源码输入，清理样式、空段落、危险标签，处理图片宽度、小标题、禁词、指定规则和表格行列删除。
导航填充 从源导航提取父级和子级，再填入目标模板；可选择提取没有子级的父级导航。
联系方式替换 从联系人文本提取公司、联系人、电话、邮箱、地址等字段，并替换到现有 HTML 联系区域。
文本处理 处理空格、空行、大小写、标点转换、去重、排序、编号等纯文本整理任务，并支持连续处理结果。
图片链接替换 按顺序替换 HTML 和 CSS 里的图片链接，可选择全部图片、仅背景图片或排除背景图片。
草稿和工作区 主要输入区自动保存，支持导出工作区 JSON，也可以导入恢复当前工作内容。

基本使用

  1. 打开主页面，选择顶部对应工具。
  2. 把源内容粘贴到左侧输入区，也可以点“填入示例”快速试用。
  3. 根据工具需要调整设置，例如导航子产品显示数量、HTML 格式化规则或图片替换模式。
  4. 查看提取结果或预览内容，确认无误后生成、复制或导出。
  5. 清空后可以点“撤回”恢复刚清掉的内容；跨设备迁移时用“导出工作区”和“导入工作区”。

更新记录

2026-08-24

格式化预览批量加粗

  • 预览工具栏新增“批量选择加粗”：开启后输入/预览会平滑切换为 40% / 60%，可依次选择多段不连续的词或短句，暂存内容会以浅色标记显示。
  • 选错时可撤回最后一次选择；点击“应用加粗”后一次写入全部选区，并自动同步输出源代码；取消批量选择不会改动正文。
  • 所有功能的操作提示统一上移，避免遮盖页面底部按钮。
  • 修复上移后的提示框隐藏不完整问题，提示结束后会完整滑出视口。
  • 批量模式宽度切换改为同轨道动画，窄屏保持单列；底部操作条改为淡入展开，减少布局跳变。
2026-08-21

HTML 格式化标点转换

  • HTML 格式化新增“中文标点转英文”和“英文标点转中文”两个可选项，只处理正文文字，不改动标签、属性或图片链接。
  • 修复括号转换映射：（/） 会分别正确转换为 (/)，反向转换也保持左右括号对应。
2026-08-21

不可断行连字符显示修复

  • 从 Word 或 WPS 粘贴内容时，格式化会把不可断行连字符及其 WPS 控制字符形式转换为普通 -，避免预览中显示为小方块。
  • 图片链接替换新增“一链全换”：开启后，用第一条新链接覆盖当前模式下的全部匹配图片链接。
2026-08-19

格式化预览表格编辑

  • 预览工具栏的加粗功能调整为更清晰的“加粗选中文本”按钮。
  • 点击表格单元格后，可删除该单元格所在的行或列，修改会自动同步到输出源代码。
2026-08-19

文本处理连续清理优化

  • “去空行”现在兼容 Windows、Mac 和 Linux 换行，并会删除含空格、Tab、全角空格或不可见空白字符的空行。
  • 连续点击处理按钮会自动继续处理上一次结果；手动修改源文本后会重新开始。
2026-07-23

HTML 格式化图片保留修复

  • 修复段落按换行拆分时，纯图片段会被误判为空并删除的问题；格式化后图片会继续保留并单独居中成段。
2026-07-10

HTML 格式化卡顿修复

  • 修复列表项中嵌套段落或 div 时可能进入死循环的问题，避免点击“一键格式化”后浏览器长时间卡死。
2026-07-09

HTML 格式化输出稳定性优化

  • 右侧预览工具栏新增加粗按钮，选中文本后可一键加粗或取消加粗，并同步更新源代码。
  • 优化 AI 辅助识别后的输出兜底：如果后处理结果意外为空，会保留原始纯文本，避免提示成功但右侧无内容。
  • 图片链接替换新增“不替换背景图片”模式，批量换图时可保留 `background` 和 `background-image` 中的原背景图。
2026-07-08

HTML 格式化兼容性优化

  • 新增“Markdown格式”开关，开启后可处理豆包等工具复制出的 Markdown 文本，标题统一转为加粗段落。
  • Markdown 模式下跳过自动小标题识别，避免同一段内容被二次识别导致异常加粗。
  • 小标题识别改为保守规则，短句不再仅凭“短 + 无标点”被加粗，减少型号、产品名和功能点误判。
  • 优化多行列表项清理，列表项内部的多行说明会拆成独立段落，同时继续去掉列表点号。
  • 新增“AI辅助识别”入口，可通过 Cloudflare Worker 调用 Qwen 判断小标题；失败时自动回退本地规则。
2026-07-07

导航提取增强
