# 建站工具箱使用说明

## 1. 工具定位

建站工具箱是一个本地静态网页工具，不依赖后端服务，主要用于把建站素材整理成更干净、更适合粘贴到网站后台或模板中的内容。

适合处理：

- 从 Word、网页、旧站后台复制出来的杂乱富文本或 HTML
- 产品栏目、新闻栏目、二级导航等重复导航结构
- 公司联系方式代码块的批量替换
- 禁词、敏感词、旧品牌词的替换
- 图片链接迁移
- 简单纯文本清洗

不适合处理：

- 需要完整网页渲染、复杂组件状态或服务端模板语法的项目
- 需要保证 HTML 语义完全不变的精密代码
- 大型站点的全量自动迁移
- 需要登录、抓取、发布或远程接口调用的流程

## 2. 打开与数据存储

### 2.1 打开方式

可以直接打开 `index.html`。如果浏览器因为本地文件权限导致默认禁词库无法加载，请在项目目录启动静态服务：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173/
```

### 2.2 本地保存

主要输入区会自动保存到浏览器 `localStorage`。刷新页面后，未完成内容会自动恢复。

会保存的内容包括：

- HTML 格式化输入和输出
- 导航源代码、目标模板和输出结果
- 联系人文本、联系方式代码和输出结果
- 文本处理输入和输出
- 图片链接替换输入和输出

注意：

- 自动保存只存在当前浏览器、当前域名或当前本地文件环境中。
- 清空某个工具区时，会同步清除该工具区相关草稿。
- 浏览器清理站点数据后，草稿和禁词库会丢失。

### 2.3 工作区导入导出

顶部提供“导出工作区”和“导入工作区”。

- 导出文件名默认为 `site-toolbox-workspace.json`。
- 导出内容只包含当前主要输入区中有值的字段。
- 导入时只恢复工具箱已识别的字段，其他字段会被忽略。
- 工作区文件用于迁移当前工作内容，不等同于项目配置备份。

## 3. HTML 格式化

### 3.1 用途

HTML 格式化用于清理富文本或 HTML 片段，生成更规整的正文结构。

常见使用场景：

- 从 Word、公众号、旧后台复制产品详情
- 清理内联样式、冗余标签、空段落
- 把标题转换成统一的加粗段落或 H3
- 给图片居中、统一宽度
- 替换禁词
- 输出可复制的干净富文本或源代码

### 3.2 输入方式

有两个输入标签：

- **富文本**：直接粘贴可视化内容，适合从网页或 Word 复制。
- **源代码**：粘贴 HTML 代码片段，适合从后台源码或模板中复制。

点击“一键格式化”后，右侧会显示预览和源代码两个输出标签。

### 3.3 基础清理规则

格式化会按以下顺序整理内容：

- 将没有段落结构的 `div`、`section` 等普通块尽量转成段落。
- 拆分标题中的 `<br>`，避免一个标题里混入多段内容。
- 拆分顶层换行，把连续文本整理成段落。
- 删除 Word 条件注释、普通 HTML 注释和命名空间标签。
- 将 `&nbsp;`、制表符、异常空白整理成普通空格。
- 将 `<b>` 统一转成 `<strong>`。
- 将列表项拆成段落，去掉 `ul`、`ol` 外壳。
- 去掉链接标签，只保留链接文字。
- 去掉 `figure`、`span`、`font`、`blockquote`、`em`、`u` 等常见包裹标签，只保留内容。
- 展平嵌套段落。
- 删除无文字、无图片、无表格的空段落。
- 中文字符和中文标点之间多余空格会被清理。

### 3.4 清理规则开关

左侧“清理规则”中有几个主要开关：

- **清理样式**：删除大多数属性和内联样式。图片保留 `src`、`alt`、`width`、`height`，表格单元格保留 `colspan`、`rowspan`。
- **段落缩进**：给普通段落添加 `text-indent: 2em`。表格内段落不会缩进。
- **保留加粗**：保留原文中的 `<strong>`/`<b>`。关闭后会移除已有加粗。
- **自动小标题**：根据文本长度、标点、关键词、上下文等规则识别小标题。

### 3.5 小标题规则

自动小标题有两个设置：

- **规则：通用**：兼顾中文和英文内容。
- **规则：英文**：更偏向英文标题识别。
- **输出：加粗**：把识别到的小标题包成 `<strong>`。
- **输出：H3**：把识别到的小标题转成 `<h3>`。

自动识别会倾向判断以下内容为小标题：

- 较短的独立段落
- 没有句号、问号、感叹号等结束标点
- 包含“特点、优势、功能、参数、应用、详情、说明、步骤、服务、案例、质保、售后、常见问题”等标题词
- 包含 `1.`、`一、`、`（一）` 等编号样式
- 前后段落明显更长

不会自动识别为小标题的常见情况：

- 表格内文字
- 已经加粗的文字
- 缩进段落
- URL
- 太长的句子
- 以明显陈述语气开头的普通正文

### 3.6 指定规则

“指定规则”面板默认收起，可手动展开。

支持三类规则：

- **指定标题加粗**：每行一个标题，按标签纯文本精确匹配。匹配到的普通块会整体加粗。
- **指定文字加粗**：每行一个文字，匹配正文中的文字片段，并用 `<strong>` 包裹。
- **指定文字加类名**：每行一个文字，按标签纯文本精确匹配，给匹配块追加指定类名。

整理规则：

- 每行一条。
- 空行会忽略。
- 重复项会去重。
- “指定标题加粗”和“指定文字加类名”是精确匹配整段文字。
- “指定文字加粗”是匹配文字片段。
- 指定类名只能包含字母、数字、下划线、中横线，且不能以数字开头。
- 已经加粗的文字不会重复包裹。

### 3.7 图片处理

图片相关功能：

- **去除图片**：删除输入内容中的所有 `<img>`。
- **图片宽度**：可以设置 `50%`、`80%`、`100%`、`500px`、`700px` 或自定义宽度。
- 图片所在段落会自动居中，并取消首行缩进。
- 如果一个段落里同时有图片和文字，工具会尽量拆成图片段落和文字段落。
- 设置图片宽度后，会给输出图片写入 `width`，并移除 `height`。

限制：

- 图片宽度只处理输出内容里的 `<img>`。
- 背景图不属于 HTML 格式化的图片宽度处理范围。
- 如果原始 HTML 结构严重破损，图片和文字拆分结果可能需要手动检查。

### 3.8 禁词替换

启用“禁词替换”后，格式化输出会应用禁词库。

禁词库支持：

- 手动添加：输入“禁词”和“替换为”。
- 空替换：替换词可以为空，表示删除该词。
- 导出：导出为 `禁词库.txt`，格式为 `禁词=替换词`。
- 导入：支持 `.txt`、`.csv`、`.json`。
- 批量添加：每行一条，支持 `禁词=替换词`、Tab 分隔、英文逗号或中文逗号分隔。
- 清空全部后可以撤回一次。

整理规则：

- 禁词按普通字符串替换，不按正则表达式处理。
- 替换顺序按禁词库当前顺序执行。
- JSON 导入格式为数组，每项包含 `word` 和 `replacement`。
- 本地禁词库存储在浏览器 `localStorage`。
- 默认禁词库来自项目根目录的 `forbidden-words.json`。

限制：

- 不会自动识别词边界，短词可能替换到长词内部。
- 不会处理同音词、繁简转换或语义相近词。
- 禁词替换是在 HTML 字符串上执行，替换词如果包含 HTML 会作为 HTML 进入结果，请谨慎使用。

### 3.9 安全清理

格式化输出会删除或清理常见危险内容：

- 删除 `script`、`iframe`、`object`、`embed`。
- 删除 `onclick`、`onerror`、`onmouseover` 等内联事件属性。
- 删除 `srcdoc`。
- 删除 `href="javascript:..."` 和 `src="javascript:..."`。

限制：

- 这是面向建站内容整理的安全清理，不是完整的 HTML 安全沙箱。
- 不建议把不可信来源的复杂 HTML 直接作为最终发布内容。

### 3.10 查找替换和复制

输出预览区支持查找替换：

- 查找下一处
- 替换当前
- 全部替换

复制规则：

- 在预览中复制，会同时写入干净 HTML 和纯文本。
- 点击“复制结果”时，会根据当前输出标签复制预览富文本或源代码。

## 4. 导航填充

### 4.1 用途

导航填充用于从旧导航代码提取栏目，再填充到另一个目标模板中。

适合：

- 产品中心栏目迁移
- 新闻资讯栏目迁移
- 多个父级栏目和子栏目批量填充

### 4.2 源导航识别规则

源导航代码优先识别以下结构：

- 父级导航项：`.itemNav`
- 子级导航容器：`.navchildlist`
- 子级行：`.level_2_content.navchildLine`、`.child_content_list > .navchildLine`、`.navchildPart > .navchildLine` 或 `.navchildLine`
- 链接：`a[href]`
- 标题文字：`.pageLink`、`.nav_item_name`、`.navchildLink`、`.level_2_title`，没有这些类时取链接文字

整理规则：

- 只取第一个 `.basic_navbar` 容器，避免页面里重复导航导致重复提取。
- 父级和子级容器按出现顺序配对。
- 没有子级链接的父级通常不会作为有效项输出。
- 提取后可以手动勾选父级和子级，未勾选的不参与生成。

### 4.3 目标模板识别规则

目标模板需要有可识别的重复块。

工具会：

- 在模板中查找至少两个同类兄弟元素，作为重复模块。
- 取第一个重复模块作为模板。
- 删除原有重复模块。
- 根据勾选的导航项重新生成模块。
- 优先替换模块中的父级链接和文字。
- 如果模块内部存在可识别的子级重复项，会按父级保留子级结构。
- 如果模块内部没有子级模板，会把勾选的子级扁平化为一组导航项。

### 4.4 子产品数量限制

“子产品数量”默认是 `4`。

规则：

- 如果某个父级下的子级数量大于“限制值 + 1”，只保留前 N 个子级。
- 末尾追加一个“更多xxx”链接，指向父级链接。
- “更多xxx”会尝试去掉“中心、展示、资讯、列表、分类、大全、推荐、项目、栏目、频道、专区”等后缀。

例如：

- 父级“产品中心”会生成“更多产品”。
- 父级“新闻资讯”会生成“更多新闻”。

### 4.5 限制

- 目标模板必须有至少两个同类重复块，否则无法识别。
- 源导航结构如果不是 `.itemNav`/`.navchildlist` 风格，需要先手动整理。
- 复杂多级导航只按父级和二级子级处理。
- 生成结果应人工检查链接、数量和结构是否符合目标站点。

## 5. 联系方式替换

### 5.1 用途

联系方式替换用于把新的公司、联系人、电话、邮箱、地址等信息替换进已有联系方式 HTML 代码块。

### 5.2 联系人文本提取规则

支持的常见标签包括：

- 公司：公司名称、公司名、企业名称
- 联系人：联系人、姓名、业务联系人、负责人
- 手机/电话：联系电话、电话、手机、手机号、服务热线、咨询热线、客服热线、联系方式
- 座机：座机号码、座机、400电话
- 邮箱：电子邮箱、邮箱、邮箱地址
- 地址：公司地址、联系地址、详细地址、办公地址、厂家地址、地址
- 其他：传真、邮编、QQ、微信、网站、网址、官网

支持格式：

```text
公司名称：星河科技有限公司
联系人：张三
手机：13800138000
电子邮箱：hello@example.com
办公地址：广东省深圳市南山区科技园
```

也支持标签和值用 Tab 分隔。若标签后面没有值，会尝试取下一行作为值。

### 5.3 HTML 字段识别规则

工具会从目标 HTML 中识别联系方式候选块，并给出替换预览。

识别依据包括：

- 文本标签，如“联系人、电话、邮箱、地址”
- `mailto:`、`tel:` 链接
- class、id、title、alt、aria-label、href、src 中的关键词
- Font Awesome 图标类，如 `fa-phone`、`fa-envelope`、`fa-map-marker`
- 常见值格式，如手机号、座机、邮箱、地址
- 表格行、列表项、段落、卡片式联系方式结构

### 5.4 替换流程

1. 在“联系人信息”中粘贴新联系方式。
2. 工具会自动提取字段，也可以手动修改提取结果。
3. 在“联系方式代码”中粘贴目标 HTML。
4. 点击“替换”。
5. 在预览弹窗中检查每一行识别到的类型。
6. 可把某行改为其他字段，或选择“不替换”。
7. 点击“执行替换”生成结果。

### 5.5 替换规则

- 电话和座机会同步更新 `tel:` 链接。
- 邮箱会同步更新 `mailto:` 链接。
- 有标签和值的结构会尽量保留标签，只替换值。
- 表格行会优先把标签后一格作为值。
- 有 `value`、`content`、`text`、`desc` 等类名的元素会被优先视为值容器。

### 5.6 限制

- 复杂嵌套、非标准命名或纯图片联系方式可能无法准确识别。
- 多个同类字段只会按当前提取值和预览选择替换，不会理解业务上下文。
- 替换后建议检查电话链接、邮箱链接和地址文本。

## 6. 图片链接替换

### 6.1 用途

图片链接替换用于把新图片 URL 按顺序替换进 HTML/CSS 代码。

### 6.2 输入规则

“新图片链接”支持两种输入：

- 一行一个图片链接。
- 粘贴包含多个 `<img src="...">` 的 HTML 片段，工具会提取其中的 `src`。

“页面代码”支持：

- `<img src="...">`
- `srcset="..."`
- CSS `url(...)`
- `background` 或 `background-image` 中的 `url(...)`

### 6.3 替换模式

- **全部图片链接**：替换 `img src`、`srcset` 和所有 `url(...)`。
- **仅背景图片**：只替换 `background` 或 `background-image` 中的 `url(...)`。
- **不替换背景图片**：替换 `img src`、`srcset` 和非背景用途的 `url(...)`，保留 `background` 或 `background-image` 中的图片链接。

### 6.4 替换规则

- 按代码中出现顺序替换。
- 新链接数量和可替换位置数量不一致时，只替换两者较少的数量。
- 工具会显示已替换数量、未使用链接数量、剩余未替换位置数量。

限制：

- 不会下载、验证或压缩图片。
- 不会判断图片尺寸是否匹配原位置。
- 复杂 JS 拼接字符串里的图片地址通常不处理。

## 7. 文本处理

### 7.1 空格处理

- **去首尾空格**：逐行删除行首和行尾空格。
- **合并空格**：把连续空格、Tab、全角空格合并为一个普通空格。
- **删除空格**：删除空格、Tab、全角空格。
- **去空行**：删除仅含普通空格、Tab、全角空格或不可见空白字符的空行，兼容 Windows、Mac 和 Linux 换行。
- **连续处理**：第一次从源文本开始；之后点击其他处理按钮会自动继续处理上一项结果。手动修改源文本后，会清空旧结果并重新开始处理链。

### 7.2 大小写

- **全大写**：转为大写。
- **全小写**：转为小写。
- **首字母大写**：按句首或分隔符后首字母大写。

### 7.3 标点转换

- **中文转英文**：把常见中文标点转为英文标点。
- **英文转中文**：把常见英文标点转为中文标点。

限制：

- 标点转换是字符映射，不会理解语境。
- 引号、破折号、省略号等复杂标点转换后可能需要人工检查。

### 7.4 行处理

- **单换行**：把连续多个换行压缩为一个换行。
- **合并为一行**：删除所有换行。
- **按行去重**：按整行去重，空行会被移除。
- **按行排序**：移除空行后按中文本地排序。
- **每行编号**：移除空行后给每行添加 `1. `、`2. ` 这样的编号。

### 7.5 回填和复制

- “结果回填到源文本”会把输出区内容放回输入区，便于连续处理。
- “复制结果”复制输出区内容。

## 8. 清空与撤回

每个主要工具区都有“清空”和“撤回”。

规则：

- 清空会把当前工具区主要输入/输出内容保存为一次可撤回快照。
- 点击“撤回”可恢复上一次清空前的内容。
- 每个工具区的撤回互相独立。
- 撤回主要用于误清空恢复，不是完整历史记录。

## 9. 示例数据

每个工具区提供“填入示例”。

用途：

- 快速查看工具处理效果。
- 对照示例格式整理自己的输入。
- 手动验证页面功能是否正常。

## 10. 整理规则总览

### 10.1 推荐处理顺序

整理产品详情时，建议：

1. 先在 HTML 格式化中粘贴富文本或源代码。
2. 根据需要设置清理样式、段落缩进、保留加粗、自动小标题。
3. 有固定标题或特殊词时，再使用指定规则。
4. 如需统一图片，设置图片宽度。
5. 如需禁词替换，先检查禁词库再启用。
6. 一键格式化后，在预览和源代码中检查。
7. 再复制到目标后台。

迁移导航时，建议：

1. 先提取源导航。
2. 勾选需要的父级和子级。
3. 粘贴目标模板。
4. 设置子产品数量限制。
5. 生成后检查“更多”链接和模块数量。

替换联系方式时，建议：

1. 先提取联系人信息并校正字段。
2. 再粘贴联系方式代码。
3. 在替换预览中逐行确认字段类型。
4. 执行替换后检查 `tel:` 和 `mailto:`。

### 10.2 输入整理建议

- 粘贴前尽量只复制需要处理的区域。
- 不要把完整页面、脚本和样式全部塞进 HTML 格式化，除非只是临时清理。
- 导航模板至少保留两个重复项，方便工具识别结构。
- 联系方式模板尽量保留标签文字或语义化 class。
- 图片链接替换时，先确认新旧图片顺序一致。

### 10.3 输出检查清单

复制结果前建议检查：

- 段落是否被错误拆分或合并。
- 小标题是否识别过多或过少。
- 图片是否全部保留、居中、宽度正确。
- 禁词是否误替换。
- 链接是否被保留或按预期删除。
- 导航数量和层级是否正确。
- 电话、邮箱、地址是否替换到正确位置。

## 11. 已知限制

- 工具偏向“建站内容整理”，不是通用 HTML 格式化器。
- HTML 格式化会主动删除很多标签和属性，不适合保留复杂交互组件。
- 自动小标题是启发式判断，不保证 100% 准确。
- 导航填充只处理父级和二级子级，不处理任意深度导航。
- 联系方式替换依赖文本、类名、链接和图标线索，结构过于特殊时可能识别失败。
- 图片链接替换只做字符串级顺序替换，不理解页面布局。
- 禁词替换不按正则、不按词边界、不做语义判断。
- 本地草稿和禁词库依赖浏览器本地存储，换浏览器或清数据后不会保留。
