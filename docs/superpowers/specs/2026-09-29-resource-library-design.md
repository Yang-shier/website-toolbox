# 建站资料库工作区设计

日期：2026-09-29  
状态：待用户确认书面设计

## 1. 目标

把 `常用网址及代码.xlsx` 中需要频繁查找的资料直接整合进现有建站工具箱。用户打开工具箱后，应能在一次搜索和一次选择内找到网址、内网共享路径、代码片段、AI 提示词或 Banner 样式，并直接打开目标网址或复制所需内容，不再依赖 Excel 目录逐项查找。

本功能是现有单页工具箱中的新工作区，不创建独立站点，也不改变 HTML 格式化、导航填充、联系方式替换、文本处理和图片链接替换的既有行为。

## 2. 已确认范围

- 在当前页面内部增加“资料库”入口，点击后切换主内容区，不跳转到独立资料页面。
- 采用桌面端三栏结构：分类、结果列表、详情。
- 顶部提供跨分类搜索。
- 内网共享路径按公共前缀分组，界面只显示差异路径，复制时恢复完整 UNC 路径。
- 合并标题和内容完全相同的重复项。
- 标题相同但内容不同的条目保留为不同版本，不擅自删除。
- 常用代码按 HTML、CSS、JavaScript、混合模块和快速修复进行整理。
- 第一版只提供查找、打开和复制，不增加在线编辑、代码执行、收藏、历史记录或云同步。

## 3. 信息架构

资料库包含以下分类：

1. 全部
2. 常用网址
3. 内网共享
4. HTML 模块
5. CSS 样式
6. JavaScript
7. HTML + CSS + JavaScript
8. 快速修复
9. AI 提示词
10. Banner 样式

每个条目使用稳定且唯一的 `id`，并包含适用字段：

- `title`：用户看到的名称。
- `category`：主分类。
- `tags`：如 `3.0`、`4.0`、`手机端`、`表格`、`导航`、`地图`、`图片`。
- `description`：一句话说明用途；原表没有可靠说明时保持简短，不推测业务规则。
- `aliases`：搜索别名。
- `url`：外部网址。
- `basePathKey` 和 `relativePath`：内网路径的公共前缀引用和差异路径。
- `content`：单一代码或提示词内容。
- `parts`：需要分别复制的 HTML、CSS、JavaScript、H1、P 等内容。
- `variantLabel`：同名不同内容时显示的版本名。

原工作簿中的隐藏“目录”页只用于核对标题，不直接生成资料条目。目录中没有对应正文或真实链接的项目不会被凭空补全。

## 4. 页面入口

在页头次级操作区增加“资料库”按钮，位置与“版本更新说明”“导出工作区”“导入工作区”同组。原因如下：

- 现有五个顶部标签都是内容处理工具，资料库属于查找入口，语义不同。
- 顶部工具标签在窄屏已经需要横向滚动，再增加第六个标签会降低可见性。
- 次级入口仍在同一页面内切换，符合“直接在工具箱里查看”的要求。

进入资料库后，按钮显示激活状态。切换回任意现有工具时，保留本次搜索词和分类选择，避免来回查资料时丢失位置。

## 5. 桌面端布局

资料库主区域分为三部分：

### 5.1 顶部搜索区

- 一个明显的搜索框，提示文字为“搜索网址、路径、代码、提示词……”。
- 搜索范围包含标题、别名、标签、说明和正文内容。
- 显示当前结果数。
- 清除按钮只清除搜索词，不改变当前分类。

### 5.2 左侧分类栏

- 固定显示分类名称和条目数量。
- “全部”为默认项。
- 分类栏仅负责过滤，不承担展开正文。

### 5.3 中间结果列表

每项显示：

- 标题。
- 类型标签。
- 适用版本或场景标签。
- 一句用途说明或路径摘要。

列表项不直接铺开长代码。选中后在右侧显示完整内容，避免页面变成长表格。

### 5.4 右侧详情区

- 网址：显示说明、完整网址、“打开网址”和“复制网址”。
- 内网共享：显示路径组名称、精简路径和“复制完整路径”。
- 单一代码：显示代码类型、说明、代码块和“复制代码”。
- 混合代码：按 HTML、CSS、JavaScript 分页，并提供分段复制和复制全部。
- AI 提示词：保留原始换行，突出需要替换的占位内容，提供复制按钮。
- Banner 样式：按 H1、P、CSS 分页展示并分别复制；有可用原图时显示样式缩略图。

代码使用纯文本渲染，不通过 `innerHTML` 执行。第一版不运行工作簿里的 `<script>`，也不直接把 HTML 片段插入主页面。

## 6. 移动端和窄屏

- 小于 760px 时，左侧分类栏变为顶部横向分类条。
- 结果列表占满主区域。
- 点击条目后打开全宽详情层，并提供明确的返回列表按钮。
- 复制、打开和关闭按钮保持可点击尺寸，不依赖悬停操作。

## 7. 内网路径处理

公共前缀单独保存在路径组中，例如：

- `资料编辑组`：`\\172.16.0.4\无锡研发\T云交付\交付\资料编辑组\`
- `建站组`：`\\172.16.0.5\无锡研发\建站组\`

条目只存并显示公共前缀之后的相对路径。复制时通过 `basePath + relativePath` 生成完整路径。

由于 HTTPS 页面通常不能可靠地直接打开 Windows UNC 路径，第一版把“复制完整路径”作为稳定操作。复制成功后使用现有 toast 提示“已复制完整路径，可粘贴到文件资源管理器地址栏”。

路径前缀合并只减少重复显示，不构成隐私保护。当前网站和 GitHub 仓库公开时，完整前缀仍会存在于前端数据文件中；本设计按用户已确认的可接受范围保留这些数据。

## 8. 代码分类和去重规则

### 8.1 初始分类

- 只含 `<style>` 或主要内容为 CSS 声明：`CSS 样式`。
- 只含 `<script>`、jQuery、`document` 或 JavaScript 函数：`JavaScript`。
- 主要内容为 HTML 结构：`HTML 模块`。
- 同一条中包含两个或三个语言部分：`HTML + CSS + JavaScript`，并拆入 `parts`。
- 一两行属性、选择器修补或临时覆盖：`快速修复`。

人工复核优先于自动识别。分类不确定时保留为混合代码，不删除内容。

### 8.2 去重

- 规范化换行和首尾空白后，标题与内容都相同：合并为一条并合并标签。
- 标题相同、内容不同：分别保留，并根据适用平台或出现顺序标为不同版本。
- 没有标题但明显是上一条续写的行：并入上一条。
- 相同内网完整路径：只保留一条，合并名称或别名。

### 8.3 示例数据

具体手机号、地图坐标、客户图片、PDF 或嵌入链接不自动视为通用模板。若代码用途依赖这些值，条目说明应标明“复制后请替换示例数据”。第一版不主动改写原代码语义。

## 9. 数据和代码边界

为避免继续扩大已经较大的主 HTML 文件，资料内容和搜索逻辑独立存放：

- `src/toolbox-resource-data.js`：整理后的结构化资料数据。
- `src/toolbox-resources.js`：搜索、过滤、路径还原、详情选择和复制数据的纯逻辑。
- `建站工具箱.html`：资料库页面结构、样式、DOM 绑定和现有页面切换接入。

数据模块采用与现有 `toolbox-core.js`、`toolbox-examples.js` 和 `toolbox-storage.js` 一致的浏览器全局导出方式，不引入打包器或新的线上依赖。

## 10. 交互和错误处理

- 搜索无结果：显示“没有找到相关资料”，并提供清除搜索按钮。
- 条目内容缺失：仍显示标题，但禁用复制按钮并标明缺少的内容，不生成虚假值。
- 剪贴板复制失败：回退到兼容复制方式；仍失败时显示错误 toast。
- 外部网址为空或格式无效：禁用打开按钮，只允许查看说明。
- 内网路径只提供复制；不把无法验证的直接打开行为包装成可用功能。
- 搜索和切换分类不修改资料数据。

## 12. 验证范围

### 12.1 数据验证

- 所有条目 ID 唯一。
- 分类值属于允许集合。
- 标题和内容完全相同的重复项已消除。
- 同名不同内容条目仍然保留。
- UNC 路径公共前缀与相对路径组合后等于原始完整路径。
- 工作簿中没有实际正文或链接的目录项没有被虚构。

### 12.2 逻辑测试

- 搜索命中标题、别名、标签、说明和正文。
- 分类过滤与搜索可以叠加。
- 清除搜索后保留分类。
- 网址、代码、提示词和路径返回正确的复制内容。
- 混合代码分段复制与复制全部结果正确。

### 12.3 页面结构测试

- 资料库入口、页面容器、搜索框、分类区、结果区和详情区存在。
- 数据脚本在行为脚本之前加载。
- 原有五个工具入口和页面 ID 保持不变。
- 用户可见功能同步写入使用说明和版本更新说明。

### 12.4 浏览器验收

- 桌面端完成：进入资料库、搜索、分类、查看详情、打开网址、复制代码、复制完整内网路径。
- 窄屏完成：分类横向切换、列表阅读、详情打开和返回。
- 验证代码文本没有被当作 HTML 或脚本执行。
- 将静态测试、浏览器操作、本地提交、远程发布和线上访问作为独立结果报告。

## 13. 非目标

第一版不包含：

- 直接在网页内编辑或保存资料。
- 自动读取用户桌面的 Excel。
- 在线执行或实时预览任意代码片段。
- 收藏、最近使用和跨设备同步。
- 绕过浏览器限制直接启动 Windows 文件资源管理器。
- 自动发布到 GitHub Pages。
